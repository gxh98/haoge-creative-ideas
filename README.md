# 昊哥-创意点子（haoge-creative-ideas）

> 创意不是灵感，是工程学。给一门真实生意，出得出一批点子，也筛得出一份能落地的方案。

## 为什么有它

问 AI「帮我想几个创意」，它会给你十个听着热闹、一个都用不了的点子。

问题不在 AI 不够聪明，在**没人告诉它创意是有工序的**：

| 出创意真正需要 | 大多「点子生成器」的做法 |
|---|---|
| 先看清问题是什么 | 直接开始想点子 |
| 一次只用一个方法，往死里想 | 十个方法各说一句 |
| 发想时不管对错，评判时另开一轮 | 一边想一边否，想到第三个就卡住 |
| 每个点子都要过「能不能实现」这一关 | 只比谁更奇 |
| 最后收成一个第一步就能做的动作 | 丢一张清单给你自己挑 |

这个技能把郝广才《创意思维课》27 讲的工序完整搬进来，并且**把发想和评判强制分开**——这是整门课最硬的一条纪律，也是绝大多数点子工具死掉的地方。

## 七步主流程

| 步 | 动作 | 关键约束 |
|---|---|---|
| 1 | 澄清 | 最多问 3 个问题，问不出来就按已知条件往下走 |
| 2 | 问题卡 | 三层追问 + 群体问题 + 笨问题自检 + 换个口子 |
| 3 | 扫三陷阱 | 标准答案 / 固有习惯 / 直线思维 |
| 4 | 选 2~3 个方法 | 按难题类型路由，不贪多 |
| 5 | 独立发散 | 只发想，不评判，先要量 |
| 6 | 分开评判 | 独创性 × 实现性 两维打分，选出「大创意」 |
| 7 | 方案输出 | 首选 + 第一步动作 + 风险 + 备选 |
| 8 | 传播校验 | 用 10 条传播法则过一遍，看它传不传得出去 |

## 三种用法

- **完整流程**（默认）：七步走完，出首选方案 + 备选 + 第一步动作
- **单点发散**：指定某个方法，如「用附身术想想」「用再定义拆一下」
- **传播校验**：已有方案，只用 10 条传播法则做体检

## 一条铁律：发想与评判必须分开

想的时候不许判，判的时候不许想。

课程里的奥斯本头脑风暴七步骤、635 传递法，本质都在做同一件事——**把「这个不行」这句话推迟到该说的时候再说**。人在发散阶段一旦开始自我审查，产量会掉到十分之一。

所以这个技能在第 5 步只准出点子、不准打分；到第 6 步才把独创性和实现性两把尺子拿出来。

## 一个真例子

奔驰专修店的 To C 账号卖电瓶，问题是电瓶 4~5 年才换一次，客户当下没有需求。

用这个技能跑一遍，第 2 步就把问题重定义了：**不是「怎么让他提前买一块电瓶」，是「怎么让他现在为未来的用电安全付钱」**——因为电瓶囤在车库里一样在老化，让车主提前买实物本身违背他的利益。

于是答案从「卖件」变成「卖确定性 + 履约权」：现在交付检测、健康报告、档案、救援优先和锁价权，电瓶变成到期履约的成本项。

完整过程见仓库外的实测档案，方法全部可复现。

## 来源与边界

- 方法全部蒸馏自**郝广才《创意思维课》27 讲**课程原文（共 81,059 字），不是二手转述
- 课程真实结构是 **10 个思路 + 9 个量产方法 + 10 条传播法则**
- 这是加工品，**不替代原课**。想真正学会，去听郝广才本人讲
- 训练题里 14 道是自拟补充，已逐题标注「非课程原题」，不冒充原文
- 不适用于：写代码、做市场调研、写常规文案、评估项目可行性、没有具体生意对象的空想
